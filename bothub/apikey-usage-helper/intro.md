# 团队的 codeplan 额度，它替你盯着

每天定点把团队 API Key 用量日报推到你的企微；额度用到 60 / 70 / 80 / 90% 自动分档告警——你只管收消息。

| 你现在要自己操心的 | 交给它以后 |
| --- | --- |
| 📊 团队谁的 key 用了多少，得挨个上 aiep 网页翻 | 每天定点推送团队用量日报，一条消息看全 |
| ⚠️ 额度快烧完了才发现，跑到一半的任务说断就断 | 用到 60/70/80/90% 分档自动提醒，及时控制用量 |
| 💬 临时想知道某个 key 还剩多少，还得开电脑查 | 在企微里随口一问，它当场查给你 |

**上岗以后，这样使唤它**

- 查一下团队今天的 codeplan key 用量
- alice 的 key 额度还剩多少？

> 基于 aiep 网站能力（需已启用）。想看某位同事的用量，需要对方先在 aiep 上把你加为其 Key 的关注人；只统计名称带 codeplan 的 Key。
