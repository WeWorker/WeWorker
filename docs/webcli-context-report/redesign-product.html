03 / ADAPTER CONTRACT

从查询设计开始，
声明“下一步能做什么”。

所有 Adapter 采用同一 results 合同。对象身份来自真实返回值，待补的新内容来自用户；模型只选动作。

结果字段item.id → A
→
已声明动作查看 / 修改
→
参数绑定record_id: "A"
查看供 review 的 JSON 合同
{
  "itemsPath": "$.records",
  "idField": "id", "titleField": "title",
  "actions": [
    { "id": "detail", "label": "查看详情", "command": "detail",
      "args": { "record_id": { "from": "item.id" } } },
    { "id": "edit", "label": "修改", "command": "edit",
      "args": { "record_id": { "from": "item.id" } },
      "inputs": ["body"] }
  ]
}

inputs 不覆盖已绑定 ID；数组/数字/多字段按显式 JSON 校验，不自动转类型。混合对象用 variants 区分适用动作。
