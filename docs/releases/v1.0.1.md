# WeWorker v1.0.1 Release 文案草稿

> 状态：待发布。该文档用于准备 GitHub Release 页面，不代表 `v1.0.1` 已创建或已发布。正式发布时应以实际 Release commit、安装包、签名状态和校验和为准，删除所有“发布前填写”提示后再复制到 GitHub。

WeWorker 是一个开源桌面 AI Agent，通过可扩展 Adapter 把自然语言任务转换为真实的网站操作。v1.0.1 聚焦 WebCLI 路由与网站探索可靠性，让 Adapter 的发现、生成、验证和调用过程更稳定。

## 本次亮点

- **WebCLI 路由建议**：新增 `webcli route [<adapter-id>] <request>`，可根据自然语言请求推荐当前可用的 Adapter 命令，并支持 JSON 输出和低置信度候选提示；该命令只提供建议，不直接执行网站操作。
- **只读工具生成更直接**：API 探索默认生成并验证只读工具，复杂任务仍可进入智能生成流程。
- **探索过程更稳定**：改进响应验证、证据预加载、补采回放和增量安装，降低探索与发布过程中的重复工作。
- **长任务更可靠**：提高开发者模型生成与开发运行超时，避免完整工具实现生成到一半被中断。
- **继续上次探索**：未完成的首次开发可沿用上次来源继续，无需重新选择。

## 快速开始

1. 下载并安装对应平台的 WeWorker。
2. 在设置中配置受支持的模型和 API Key。
3. 启动或连接浏览器扩展。
4. 打开目标网站并完成必要登录。
5. 输入任务，并在提交、发布、下单、支付等关键步骤前核对确认。

可以先尝试无需私人账号数据的公开场景：

```text
帮我查看 GitHub Trending 和 Hacker News 的热门项目，整理出值得关注的 AI 工具
```

## 安全与隐私

- API Key 由用户配置，不应提交到仓库、Issue、日志或截图。
- 任务内容会发送给用户选择的模型服务商，请遵守对应服务商的隐私政策。
- 网站操作使用浏览器中的当前登录态，执行结果等同于用户本人操作。
- Bridge 与本地服务不应暴露到公共网络。
- 涉及提交、发布、下单、支付、删除等外部影响操作时，请先核对再确认。

## 已知限制

- 不同网站的页面结构、登录方式和风控策略可能变化，实际能力以当前 Adapter 和网站状态为准。
- 安装包包含桌面运行时与网站探索agent，文件体积较大。
- macOS 首次打开方式及 Windows/macOS 签名状态以本次 Release 的最终说明为准。
