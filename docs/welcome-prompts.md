# 首页固定提示词

`weworker/welcome-prompts.json` 控制首页标题下方的固定快捷提示词，按数组顺序展示。`default-site.json` 继续只维护站点默认配置，不存放固定提示词。

```json
[
  {
    "id": "mail-invoices",
    "siteId": "mail.qq.com",
    "text": "打开QQ邮箱，下载我本月收到的发票"
  }
]
```

- `id`：唯一且稳定的提示词标识。
- `siteId`：所属站点，必须属于当前发行版本的站点配置及 `build-profile.json` 打包清单，且存在对应的可用 Adapter。修改文案时须核对该站点的场景和命令能力。
- `text`：按钮文案，也是点击后填入输入框的完整内容。
- 数组顺序即展示顺序，同一站点可以配置多条提示词。
- 最多展示 5 条，只展示当前已安装且启用的站点所对应的提示词；收藏、首页站点数量及站点排序不影响固定提示词。空配置、空文案或不存在的站点不会产生入口。
- `random_prompt_enabled` 仍只控制输入框中的随机占位提示，与这些固定按钮独立。固定提示词在构建时写入，不会随刷新随机变化。

点击只填入输入框，不会直接创建任务、发送消息或执行操作。卡片仅展示提示文字和箭头，不展示站点标签。卡片沿用客户端主题和紧凑样式，窄窗口自动单列显示。固定提示词在介绍文字和常用网站之间垂直居中；窗口高度不足时，上方内容可独立滚动。

首页输入框默认停靠底部，常用网站栏紧贴输入框上方，卡片保持横向滚动，列表模式可独立纵向滚动。首页内容、聊天消息区及两处输入框使用统一的 760px 最大内容宽度，窄窗口按可用宽度收缩；长文本输入时仍保留网站栏与输入框之间的间距。

工作区侧栏展开空项目时显示灰色“没有对话”，左边缘与文件夹图标对齐；收起或新增对话后隐藏该提示。搜索及标签过滤不使用此提示，避免把过滤后的空结果误报为没有对话。

开源默认配置从前五个站点各选一条固定提示词：携程、哔哩哔哩、QQ 邮箱、网易邮箱和 Gmail。内部发行版本通过既有同路径覆盖机制提供自己的 `weworker/welcome-prompts.json`，使用其自身站点的提示词。内部业务文案仅保留在内部配置仓库，公共组件不包含业务专属文案。两种版本复用同一组件和解析逻辑，不新增网络请求。
