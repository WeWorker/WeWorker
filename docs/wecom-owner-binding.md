# 企业微信主人绑定

在「设置 → 通道 → 企业微信」配置并启用机器人后，二维码位置会显示醒目的绑定引导和六位绑定码；下方「主人绑定」一行显示已绑定或未绑定状态。未完成绑定时重新打开页面，引导仍会保留。

1. 复制页面上的 `绑定 123456` 指令（示例数字以页面实际显示为准）。
2. 在企业微信中找到对应机器人，私聊发送这条指令。
3. 机器人回复绑定成功，设置页自动显示已绑定主人；无需发送 `/myid` 或手工填写 ID。
4. 按需要选择「主人拥有的权限级别」，点击「保存配置」生效。绑定本身不自动提升权限，其他用户仍为问答权限。

绑定成功后验证码失效。更换主人时点击「重新绑定」，确认后旧主人失效、权限恢复为问答权限，并生成新码。未绑定时可点击「更换绑定码」使旧码失效。切换到另一个机器人配置时，绑定状态按配置独立保存。

绑定在本地 Backend 校验，不调用模型，不写入模型对话；机器人必须已连接。群聊中不会完成绑定，连续五次输入错误会限制该发送者十分钟。已有手工填写的主人配置继续有效。

实现沿用 WeWorker Bot 的验证码生成和指令解析，普通通道仍保留原有主人权限和访客问答规则，不改为专属 Agent 的站点权限。
