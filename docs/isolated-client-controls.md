# 隔离实例的进程级控制

下面的开关只对包含相应代码的新构建生效，现有已安装客户端不会因修改源码而改变。两者仅当值精确为 `1` 时启用；不设置时保持原行为。

- `WEWORKER_DISABLE_LOGIN_ITEM=1`：本次进程不更新开机启动偏好，也不调用系统接口更改登录启动项；设置界面和托盘不提供该开关。已有系统登录启动项不会被移除。
- `WEWORKER_DISABLE_AUTOMATIC_MEMORY=1`：本次后端进程不自动检索或生成长期记忆，聊天和定时任务不会自动处理候选记忆。显式记忆管理操作不受此开关限制，也不会删除已有记忆。

Electron 启动其自己的后端时传递环境变量。如果连接了已经运行的后端，该后端的进程环境决定其行为；不能仅凭客户端启动参数或端口占用提示推断开关生效。界面仍可能访问固定后端端口，因此开启自动记忆禁用开关后，必须在开展聊天或定时任务之前确认该端口由本次使用该开关启动的后端持有；无法确认时不要使用该实例。两个开关不隔离模型配置、聊天数据、Adapter、浏览器 profile、端口或其他用户数据，也不解决这些资源的并发冲突。运行前须分别核验目录和服务归属。
