“无动作”至少要区分两种情况：登录/导航诊断、已返回完整指标属于当前结果终点；搜索结果没有详情命令、公开作品没有合法的创作者动作、空壳候选查询属于能力缺口。后者需要开发新能力，不是已有映射遗漏，也不是等待用户接接口。

没有查询入边的写命令也不等于漏适配：登录、发布新内容、创建列表没有既存对象来源；支付、批量动作和当前页面动作必须有精确对象/范围证据，不能强接任意列表。当前清单保留这些命令，不虚构参数。
