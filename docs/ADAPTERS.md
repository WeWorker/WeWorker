# Adapter 清单

本清单记录当前 WeWorker 已支持的网站 Adapter。不同网站的页面结构、登录方式和风控策略可能变化，实际使用时以当前页面状态、账号权限和工具返回结果为准。

Adapter `manifest.json` 顶层的 `enabled` 控制客户端是否展示该站点：`true` 表示启用，`false` 表示不启用；省略时默认启用。`default-site.json` 也可按发布配置关闭站点，任一处显式设为 `false` 都会隐藏该站点。

## 使用边界

- 需要认证的 Adapter 使用浏览器现有登录状态，不应在代码、Issue、测试数据、截图或日志中保存真实账号、Cookie、Token 或用户隐私数据。
- 发送、发布、下单、支付、投递、删除、关注、点赞、收藏等具有外部影响的操作必须由用户确认。
- 第三方网站、商标和服务归各自权利人所有；使用 Adapter 时仍需遵守目标网站的协议、自动化规则和所在地区适用法律。
