# 模型切换规则

设置中的保存和激活会先检测普通对话与网站探索接口。全部通过才提交配置并激活；失败保留原配置与原激活项。检测期间设置发生变化，需要重新检测。

每次设置激活都会更新全局选择版本。普通对话、网站探索、专属 Bot 和定时任务后续发起的调用使用本次激活的模型。已有会话的旧局部选择随之失效，包括未打开的历史会话和探索记录。

对话输入栏或网站探索输入栏可以单独选择模型。此选择只影响当前会话，不改变设置中的激活项或其他会话。再次在设置中激活模型，会覆盖此前的所有局部选择，即使设置中重新激活的是同一个模型。

切换不停止、重启或中途改变正在执行的回复、探索与任务。运行中的调用保留启动时的配置快照；下一次用户消息、探索续跑或任务执行才读取新选择。定时任务的结果总结沿用本次任务的快照。

局部切换只保存模型引用、思考选项和选择版本，不复制密钥。旧记录无需批量重写，后续解析时按全局版本决定是否保留局部选择。
