# 客户端深色模式检查（2026-11-05）

首次跨页面验收基线：公开仓库 `dev-1.1.0`，提交 `47c415d`。PR 将同一配色修复移植到 `dev-1.0.2`，基线 `6b6ead3`；未带入 1.1.0 的其他功能。修改限于 Renderer 配色，不改变模型、通道、文件或任务的业务行为。

## 问题与修复

- 设置卡片、选中模型卡片、后缀容器和标签使用固定白底；改为使用已有主题变量，避免深色文字与背景不匹配。
- 设置页按钮和风格卡片的部分交互状态混入固定白色；背景及混色基底随主题变化。
- 自定义风格弹窗通过 portal 挂在 `body`，无法继承设置页的深色变量；为其同步设置页的两层主题覆盖。
- 通道类型和机器人选择菜单固定使用浅绿底、深绿字；背景基于主题成功色混色，文字使用独立的成功文字色，保留浅色模式下的深绿对比度。
- 待发送消息队列、Markdown 命令块和工具执行 Tooltip 存在固定浅色背景或深色文字；统一使用主题背景、正文和边框变量。
- 取消的计划步骤详情改为使用主题背景作为混色基底。
- 关闭态开关的轨道补充深色配色，保留开关滑块的白色；浅色主题显式声明 `color-scheme: light`。

二维码白底、站点图片、开关滑块、固定深色终端与图片灯箱属于内容或独立配色，不做全局颜色替换。已有深色覆盖的技能代码区域、计划卡片继续保留原有层次。
