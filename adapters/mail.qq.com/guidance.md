# QQ 邮箱

多轮附件动作同时携带来源 emailId 和附件名；执行前先打开该邮件，无法打开则停止下载。普通未传 emailId 的附件调用保留当前邮件语义。缺少来源 ID 时不能准备可执行的多轮附件动作。

多轮会话：search-emails/get-unread-emails 按返回邮件 ID 进入 open-email；附件按原文件名生成下载计划，当前会话内不执行写操作。

新版缺失 data-mailid 时不使用主题补造 ID。新版与经典版均优先匹配精确 ID，主题片段歧义时拒绝。页面状态、导航与登录诊断不返回邮件对象，不从页面标题或可能带会话参数的 URL 猜邮件 ID。
