# 12306 使用指导

多轮绑定：车站可补充目的站与日期查询出发车次；余票行携带内部 train_no、原区间与日期，支持查看经停及票价；经停站可补充目的站查询同日出发车次。账号支持查看乘车人和订单。票价无订票入口，乘车人无编辑入口，订单无详情、支付或取消入口；这些是当前包缺少的业务能力，不应伪造命令。

用户要查火车票，先确认出发站、到达站、日期。stations 从官方车站表按中文、拼音、简称或电报码检索；同城车站不等价，北京不自动替换为北京南。trains 查余票，train 查经停，price 查指定日期区间席别价格。train/price 的 train-no 必须来自同一次路线日期查询返回的内部 train_no，不能填 G1 这样的展示车次。

示例：webcli call 12306.cn.stations --keyword=上海 --limit=5；webcli call 12306.cn.trains --from=北京南 --to=上海虹桥 --date=2026-09-29 --limit=3。日期只是示例，不能沿用到未来请求。

stations/trains/train/price 是公开查询。me/passengers/orders 使用本人已登录会话，默认遮蔽姓名、邮箱、手机、生日等；不要擅自打开 include-sensitive。服务器掩码不尝试还原。orders 对应官方“未完成订单”页及 queryMyOrderNoComplete 接口，不等于“未出行订单”或历史订单全集；返回无未完成订单时，不得推断用户没有已支付车票。旧登录标签页不证明会话失效，应以当前服务器会话核验为准。页面空文案也可能来自请求失败，只有会话、成功响应与可见空状态同时符合已核验契约时才说明为空；缺字段或接口异常仍报告未知。余票的“有/无/数字”保持原义，空字段不是无票。price 为 CNY 对应席别价格，不是锁价、出票或多人总价。此包没有抢票、购票、支付、退改签功能。

## 调用与证据

普通参数使用 --key=value；复杂结构才使用 JSON。只调用本 Skill 当前 manifest 列出的命令。用户说“第二个”“刚才那条”时保留上一轮实际 ID 和链接，不重新取列表位置代替实体。相对日期按当前日期和用户时区换算并写出实际日期；关键缺参先追问，不能从站点默认值猜用户选择。

只读页面导航由宿主在一次调用中续执行。登录和验证码由用户在连接扩展的同一浏览器中完成；login 只打开官方页并结束，不会等待 timeout 秒或宣称已经登录。whoami 不等于完整登录验收。当前要求、当前 Skill 和本轮证据优先于历史失败记忆。临时失败不能变成永久跳过工具的规则。

接口失败、验证页、字段缺失、页面空状态与真正无结果须区分。字段为 null 或空串表示未知，不补猜。返回列表不等于全站完整结果；limit 是上限。失败保留 trace，不重复相同参数盲目重试，不用降级查询宣称原命令通过。

仅在用户要求执行且目标、内容明确时提交写操作；参数不清楚时先澄清。导航准备不等于业务操作完成，写操作不得自动重放。超时后先核查站点状态，不能直接重发。
