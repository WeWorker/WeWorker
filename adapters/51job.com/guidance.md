# 前程无忧使用指导

多轮绑定：search/hot 提供职位详情和公司入口；详情仅从可信公司链接提取 encCoId；公司页提取到的职位提供详情入口。公司页未取得职位卡片时保留公司介绍，使用独立公司结果标识，职位详情动作不可执行；不能用公司名或空 jobId 发起详情调用。

search 按关键词和 area 城市查询，hot 是城市推荐职位，不是关键词搜索的替代品。detail 使用 search/hot 返回的 jobId；company 使用 encCoId（可能包含 = 的加密公司 ID），不要拿公司名称或 jobId 代替。

area 接受支持的城市名称或站点六位码；城市不确定时追问，不借用 BOSS、携程等编码。职位结果中的 salary 文本可能包含面议或不同计薪周期；缺失 salaryMin/salaryMax 为未知，不能按 0 或年薪换算。company 返回公司介绍和当前已提取职位；页面未提取到职位不能推断公司不招聘。

search/hot 使用 we.51job.com 页面上下文 API；detail/company 读取 jobs.51job.com 的 SSR 页面。遇到站点验证由用户完成，不能用延长超时掩盖重定向问题。此包只读，不投递简历、不联系招聘者。

## 调用与证据

普通参数使用 --key=value；复杂结构才使用 JSON。只调用本 Skill 当前 manifest 列出的命令。用户说“第二个”“刚才那条”时保留上一轮实际 ID 和链接，不重新取列表位置代替实体。相对日期按当前日期和用户时区换算并写出实际日期；关键缺参先追问，不能从站点默认值猜用户选择。

只读页面导航由宿主在一次调用中续执行。登录和验证码由用户在连接扩展的同一浏览器中完成；login 只打开官方页并结束，不会等待 timeout 秒或宣称已经登录。whoami 不等于完整登录验收。当前要求、当前 Skill 和本轮证据优先于历史失败记忆。临时失败不能变成永久跳过工具的规则。

接口失败、验证页、字段缺失、页面空状态与真正无结果须区分。字段为 null 或空串表示未知，不补猜。返回列表不等于全站完整结果；limit 是上限。失败保留 trace，不重复相同参数盲目重试，不用降级查询宣称原命令通过。

仅在用户要求执行且目标、内容明确时提交写操作；参数不清楚时先澄清。导航准备不等于业务操作完成，写操作不得自动重放。超时后先核查站点状态，不能直接重发。
