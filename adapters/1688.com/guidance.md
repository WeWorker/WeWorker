# 1688 批发

多轮入口：商品搜索支持详情、素材、下载链接清单与实际返回的店铺链接；商品详情支持素材和店铺；素材支持返回商品或列出下载链接。缺失店铺链接时不生成可执行店铺动作；标题未知时保持原始 null，用返回的商品 URL 作为展示标签。download 不落盘；店铺资料也不等于店铺商品列表，当前包没有后者的查询命令。

search/store/item/assets 为浏览器读取（搜索、店铺、商品详情、素材提取），访问 1688.com；download 列出商品页可提取的图片与视频素材（URL 与文件名清单，不落盘——本运行时无文件系统，请通过外部渠道下载）。whoami 校验登录并读取身份；login 仅打开登录页（写操作需确认，打开后人工完成登录再用 whoami 验证，不轮询登录状态）。商品页结构变化、反爬验证或登录墙时报错而非空结果；缺字段保留 null/空串，不补造 0 或空列表。
