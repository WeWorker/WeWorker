# 豆瓣使用指导

search 支持电影、图书、音乐；subject 当前详情支持电影和图书，不能拿电影 ID/页面冒充音乐详情。top250 是电影 Top250；movie-hot/book-hot 是各自榜单。先从搜索或列表取得 subject ID，再看详情。

photos 返回电影海报/剧照链接，type 保留来源默认 Rb；type/requested_type 是请求参数，不证明页面已按海报分类。实测该默认值的页面标题为“剧照”，用户仅要海报时须核对实际图片及页面类别，不能拿剧照凑数。download 实际保存图片，支持 photo-id 与 output；逐张 status=success 才表示保存。failed/not_attempted 不能算下载完成；预算不足时按剩余 photo-id 分批处理。二进制图片要求运行新版 Bridge；photos 返回链接不代表已经保存文件。marks/reviews 是本人标记与短评，分页有界，不能称全量历史；不要把短评当影评长文。

缺失评分和评价人数保持未知，不能补成 0。列表排序不自动表示推荐程度或当前全站排名。图书业务可能需要登录；无法读取页面时不能直接推断条目不存在。

## 调用与证据

普通参数使用 --key=value；复杂结构才使用 JSON。只调用本 Skill 当前 manifest 列出的命令。用户说“第二个”“刚才那条”时保留上一轮实际 ID 和链接，不重新取列表位置代替实体。相对日期按当前日期和用户时区换算并写出实际日期；关键缺参先追问，不能从站点默认值猜用户选择。

只读页面导航由宿主在一次调用中续执行。登录和验证码由用户在连接扩展的同一浏览器中完成；login 只打开官方页并结束，不会等待 timeout 秒或宣称已经登录。whoami 不等于完整登录验收。当前要求、当前 Skill 和本轮证据优先于历史失败记忆。临时失败不能变成永久跳过工具的规则。

接口失败、验证页、字段缺失、页面空状态与真正无结果须区分。字段为 null 或空串表示未知，不补猜。返回列表不等于全站完整结果；limit 是上限。失败保留 trace，不重复相同参数盲目重试，不用降级查询宣称原命令通过。

所有写命令遵守 manifest 的 safety/requires_confirmation；只有用户确认具体目标和内容后才提交。导航准备不等于业务操作完成，写操作不得自动重放。超时后先核查站点状态，不能直接重发。

## 安全验证跳转

已登录也可能被豆瓣跳转到 `sec.douban.com`。遇到宿主导航拒绝并显示该域名时，在连接扩展的同一浏览器中人工完成网站要求的处理，返回原电影/图书/搜索业务页，再重试原命令。不要反复新建首页、自动处理验证码，或把安全验证域加入业务执行白名单。若仍失败，保留完整错误和 trace ID；避免分享 URL 查询参数中的敏感信息。
