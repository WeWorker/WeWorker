# 发票页面

get-invoice-info 返回当前页面信息，只有已加载并提取到真实发票号码/数电号码时才提供下载动作。多轮操作自动携带 expectedIdentity，包含页面 URL、发票代码和号码；等待加载后、触发下载前及返回邮箱前均核对，换票则停止。

可明确选择 PDF/OFD/XML、下载并返回邮箱或仅返回邮箱。没有所需格式时不改下另一种格式；下载 API 报错不再自动点击重试。download-invoice、auto-download-and-return、return-to-qqmail 均为写动作。下载结果仅代表请求已发出，不证明文件保存完成，不能据此宣称已上传或已提交。示例和本轮证据仅使用公开占位票号。

原有独立命令仍可不带 expectedIdentity 操作当前页；通过会话结果发起的动作必须使用查询绑定的身份。下载路径仍使用浏览器原有相对目录能力，WebCLI 不转换业务参数类型。真实文件落盘、浏览器关闭/跳转与业务提交需另行验收。
