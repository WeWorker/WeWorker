# 百度贴吧

hot/posts/read/search 均为只读浏览器抓取（DOM 解析），访问 tieba.baidu.com；posts 支持按贴吧名与页码浏览，read 读取单帖楼层，search 搜索贴吧内容。limit 有站点上限（最大 20），页码为正整数；未登录可读公开内容，登录后可读关注内容。页面结构变化、容器缺失或重定向到验证页时报告错误而非返回空列表；字段缺失保留 null/空串，不补造 0 或空列表。

多轮会话：posts/search 结果通过原始帖子 ID 进入 read；hot 是话题榜，后续为按该话题标题搜索相关帖子，不将话题当作帖子。read 返回正文及回复，现有包没有单条回复或作者详情入口，因此显式声明无对象后续动作；翻页仍使用 read 的 page 参数。
